# Agent runtime contract

`career-zh` 是路由 Skill。Agent 先确认模式和材料范围，再读取共享规则与对应模式文件；复杂任务按模式拆开执行，不能把所有模式一次性混用。

## 触发与首步

用户提到岗位评估、简历、求职话术、面试、投递管道、职业选择、复盘、谈薪、公司调研或公开岗位扫描时触发。首步识别模式，读取 `modes/_shared.md`、对应模式文件、`cv.md`、`config/profile.yml` 和可选 `article-digest.md`。

## 输入与输出

输入来自用户粘贴的 JD、公开岗位页、本地 inbox、用户简历、求职画像、故事库和已授权的投递记录。输出必须区分事实、匹配判断、风险、待补证据和下一步动作；简历和话术只使用用户真实经历。

## 权限与副作用

- 默认只读取本地材料和公开招聘页面。
- 不绕过登录、验证码、反爬或平台权限；强登录 JD 由用户粘贴或提供公开链接。
- 写入本地 tracker、同步飞书或调用模型前，说明目标文件/租户、范围和副作用。
- 不自动投递、不自动发送消息、不自动接受 offer；这些动作必须由用户在目标平台完成。

## 降级与验证

公开页面打不开时保留用户提供的 JD，并标记来源范围。信息不足时先输出可用草稿，再列出会改变判断的待补信息。生成简历、报告或 tracker 后检查事实来源、链接、隐私字段和文件落盘状态；飞书写入后按记录或字段回读。
